# Professional Communication

**Get feedback on professional messages** from two perspectives: the recipient and a writing collaborator.

Give it your message plus context (recipient, roles, relationship, channel). It reacts as the recipient would, suggests improvements, and offers a revised message. Follow-ups get extra guidance on warm wording.

## Installation
npx skills: `npx skills add https://www.a-laughlin.com/agentic-resources --skill professional-communication -a claude-code -g`\
pnpm: `pnpm dlx skills add https://www.a-laughlin.com/agentic-resources --skill professional-communication -a claude-code -g`\
Claude plugin: `claude plugin marketplace add a-laughlin/agentic-resources` then `claude plugin install professional-communication@agentic-resources`\
gh: `gh skill install a-laughlin/agentic-resources professional-communication`\
curl: `mkdir -p ~/.claude/skills/professional-communication && curl -fsSL https://www.a-laughlin.com/agentic-resources/agent-skills/professional-communication.tar.gz | tar -xz -C ~/.claude/skills/professional-communication`\
--\
Swap `-a claude-code | ~/.claude/skills` for your agent (e.g. `cursor`, `~/.cursor/skills`, `~/.agents/skills`, …).

## Usage
In your favorite AI chat, `/professional-communication` with your Message and Context.
