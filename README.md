# Agentic Resources

Agent skills by Adam Laughlin. Browse them below.

| Skill | Description |
| :--- | :--- |
| [decide](skills/decide/README.md) | Make fast, thorough, concise decisions through incremental interrogation. Use on exact 'decide'. |
| [professional-communication](skills/professional-communication/README.md) | Aids learning communication skills. |

## Installation
npx skills: `npx skills add https://www.a-laughlin.com/agentic-resources -a claude-code -g`\
Claude plugin: `claude plugin marketplace add a-laughlin/agentic-resources && claude plugin install <skill>@agentic-resources`\
gh: `gh skill install a-laughlin/agentic-resources <skill>`

Each skill's README lists more install options, including `curl`.
